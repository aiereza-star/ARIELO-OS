✅ Simplemente **usa libremente**. No necesitas hacer nada especial.

1. **Mantén la licencia GPLv3**
   ```

   Contenido: Copia completa de GPLv3
   ```

2. **Documenta los cambios**
   ```
   Archivo: CHANGELOG.md
   Contenido: Qué modificaste y cuándo
   ```

   ```
   // Arielo OS - Modificado bajo GPLv3

   ```

   ```
   - Instrucciones de instalación
   ```
