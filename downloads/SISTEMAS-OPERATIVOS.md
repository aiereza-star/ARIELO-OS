# 🖥️ Sistemas Operativos - Arielo OS

## Plataformas Disponibles

### 1. AMD64 (64-bit) - Recomendado

La plataforma principal de Arielo OS con soporte completo.

#### Versiones

**ARIELO OS AMD64 CORE**
- Versión optimizada y ligera
- Incluye lo esencial para funcionar
- Ideal para: Sistemas con recursos limitados
- Tamaño: ~4.78 GB
- [Descargar](https://arielo-os.com/descargas.html#os-amd64)

**ARIELO OS AMD64 FULL**
- Versión completa con todas las características
- Incluye todas las aplicaciones y herramientas
- Ideal para: Sistemas con buenos recursos
- Tamaño: ~9.17 GB
- [Descargar](https://arielo-os.com/descargas.html#os-amd64)

#### Requisitos Mínimos (AMD64)
- CPU: Procesador 64-bit
- RAM: 1 GB mínimo (2 GB recomendado)
- Almacenamiento: 5-10 GB según versión
- BIOS/UEFI: Compatible con ambas

---

### 2. x86 32-bit - Compatibilidad Extendida

Para sistemas antiguos o de bajo consumo.

**ARIELO OS x86 32-bit**
- Compatible con sistemas 32-bit
- Versión ligera y optimizada
- Ideal para: Hardware antiguo, netbooks, tablets
- Tamaño: ~2.12 GB
- [Descargar](https://arielo-os.com/descargas.html#os-x86-32)

#### Requisitos Mínimos (x86 32-bit)
- CPU: Procesador 32-bit o 64-bit con soporte 32-bit
- RAM: 512 MB mínimo (1 GB recomendado)
- Almacenamiento: 2-3 GB
- BIOS: Compatible

---

### 3. ARM64 - Sistemas Embebidos

Para dispositivos ARM64 como Raspberry Pi y similares.

**ARIELO OS ARM64**
- Optimizado para arquitectura ARM64
- Versión ligera ideal para IoT
- Ideal para: Raspberry Pi, Waveshare, otros ARM
- [Descargar Apps ARM64](https://arielo-os.com/descargas.html#apps-arm64)

#### Requisitos Mínimos (ARM64)
- CPU: ARM64 (ARMv8+)
- RAM: 512 MB mínimo (1 GB recomendado)
- Almacenamiento: 2-3 GB
- Bootloader: U-Boot o compatible

---

### 4. Waveshare ESP32-S3 - MiniPC

Versión especial optimizada para la pantalla táctil Waveshare ESP32-S3 7".

**ARIELO MiniPC OS**
- Interfaz adaptada para pantalla táctil
- Rendimiento optimizado para ESP32-S3
- Ideal para: Proyectos embebidos, displays interactivos
- [Descargar](https://arielo-os.com/descargas.html)

## ✅ Verificación de Integridad

Todas las descargas incluyen un **checksum SHA256** para verificar que el archivo no ha sido modificado.

### Cómo verificar en Linux/Mac:

```bash
sha256sum ARIELO_OS_AMD64_CORE_1058.iso
```

### Cómo verificar en Windows:

```powershell
Get-FileHash -Path "ARIELO_OS_AMD64_CORE_1058.iso" -Algorithm SHA256
```

Compara el resultado con el checksum mostrado en la página de descargas.

## 🚀 Instalación Rápida

### Paso 1: Preparar el medio de instalación

1. Descarga la ISO correspondiente a tu plataforma
2. Verifica el checksum SHA256
3. Crea un USB booteable usando:
   - **Rufus** (Windows)
   - **Etcher** (Windows/Mac/Linux)
   - **dd** (Linux)

### Paso 2: Bootear desde el medio

1. Inserta el USB o DVD
2. Reinicia la computadora
3. Accede al menú de boot (generalmente F12, F2, ESC, etc.)
4. Selecciona el medio de instalación

### Paso 3: Instalar Arielo OS

1. Sigue el asistente de instalación
2. Selecciona el disco de destino
3. Configura el usuario y contraseña
4. Espera a que se complete la instalación
5. Reinicia

### Paso 4: ¡Disfruta!

Arielo OS está listo para usar.

## 💡 Consejos

- **Copia de seguridad:** Haz backup de tus datos antes de instalar
- **Particiones:** Reserva espacio suficiente para el SO y datos
- **UEFI vs BIOS:** Asegúrate de bootear en modo compatible
- **Drivers:** Algunos dispositivos pueden requerir drivers adicionales
