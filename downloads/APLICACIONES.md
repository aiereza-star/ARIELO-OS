## 🔧 Instalación de Aplicaciones

### Método 1: Aplicaciones Pre-instaladas

Las aplicaciones vienen pre-instaladas en Arielo OS y están listas para usar.

### Método 2: Descarga e Instalación Manual

1. Descarga el archivo `.zip` de la aplicación
2. Extrae el contenido
3. Ejecuta el archivo de instalación
4. Sigue las instrucciones

### Método 3: Gestor de Paquetes

Utiliza el gestor de paquetes del sistema:

```bash
# Instalar aplicación
sudo apt install nombre-aplicacion

# Actualizar aplicaciones
sudo apt update && sudo apt upgrade
```
