# 🖥️ Arielo OS

**Un sistema operativo ligero y modular diseñado para hardware de recursos limitados**

[![License](https://img.shields.io/badge/License-Free%20Software-brightgreen)](https://arielo-os.com/)
[![Official Website](https://img.shields.io/badge/Web-arielo--os.com-blue)](https://arielo-os.com/)

## 📋 Descripción

**Arielo OS** es un sistema operativo eficiente y funcional diseñado para convertir hardware modesto en un PC completo. Nuestro objetivo es demostrar que con una arquitectura modular y un diseño responsable con los recursos, cualquier dispositivo puede ofrecer una experiencia de usuario completa y práctica.

A diferencia de otros proyectos similares, Arielo OS no es solo una demostración gráfica: es un sistema operativo totalmente funcional con aplicaciones propias y utilidades reales.

---

## ✨ Características Principales

- **🚀 Ligero y Eficiente**: Optimizado para respetar al máximo los recursos del hardware
- **🔧 Modular**: Arquitectura flexible que permite personalización y extensión
- **💻 Funcional**: Incluye aplicaciones propias más allá de una simple interfaz
- **🌐 Compatible**: Disponible para múltiples plataformas (ARM64, AMD64, x86)
- **📱 Versátil**: Desde dispositivos embebidos hasta sistemas desktop
- **🔄 Híbrido**: Soporta tanto BIOS como UEFI
- **🆓 Libre**: Software de código abierto mantenido por la comunidad

---

## 📦 Aplicaciones Incluidas

Arielo OS viene con una suite de aplicaciones propias:

- 📐 **Calculadora** - Herramienta de cálculo rápido
- 📝 **Bloc de Notas** - Editor de texto simple
- 🖼️ **Visor de Imágenes** - Compatible con JPG y PNG
- 📊 **Hoja de Cálculo** - Utilidad para datos tabulares
- 📂 **Administrador de Archivos** - Navegación y gestión de ficheros
- 📋 **Visor de Registros** - Monitoreo del sistema
- ⚙️ **Información del Sistema** - Detalles técnicos del hardware

Disponibles para: **ARM64**, **AMD64**, **x86**

## 🚀 Primeros Pasos

1. **Descarga la ISO** desde [arielo-os.com/descargas](https://arielo-os.com/descargas.html)

3. **Crea un medio de instalación** (USB, DVD, etc.)
4. **Instala Arielo OS** en tu dispositivo
5. **¡Disfruta!** de una experiencia ligera y eficiente
